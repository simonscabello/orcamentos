# 05 — Revisão de segurança

Fonte: [agents/security-engineer.md](agents/security-engineer.md) (17 sondas Pest), [agents/saas-architect.md](agents/saas-architect.md), [agents/codex-audit.md](agents/codex-audit.md) e R1.

## Modelo de ameaça resumido

| Ator                              | Objetivo                                 | Superfície                                                                      |
| --------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------- |
| Usuário de outra oficina          | Ler ou alterar orçamentos alheios (IDOR) | ids sequenciais nas rotas, `exists` nos requests, `?duplicate=`, `?vehicle_id=` |
| Atacante externo                  | Tomar uma conta                          | login, forgot/reset, 2FA                                                        |
| Pessoa com o celular desbloqueado | Usar a sessão                            | sessão de 30 dias **(origin)**, troca de e-mail/senha                           |
| Conteúdo malicioso                | XSS / injeção no PDF                     | nomes, descrições, observações                                                  |

## Verificado e correto

- **IDOR:** todas as rotas de clientes, veículos, orçamentos, status e PDF devolvem 404 para outra oficina. `Rule::exists` filtra por oficina. `duplicate` e `vehicle_id` de outra oficina são ignorados sem vazar dados.
- **Mass assignment:** `business_id`, `number` e `total` vindos do request são descartados (`validated()`).
- **XSS:** o Blade do PDF escapa tudo (testado com `<script>`); o React escapa por padrão; o cookie `appearance` no script inline é escapado.
- **CSRF:** padrão do Laravel/Inertia.
- **Ferramentas de dev:** Boost e Inertia DevTools inativos em produção.
- **2FA:** confirmação e senha exigidas; cadastro público desligado (teste existente).
- **Cookies `secure`:** dependem do `trustProxies('*')`, que está presente e não deve ser removido.

## Testes de segurança existentes e adicionados

- Existentes: `EstimateTenantTest`, `EstimateUsabilityTest` (404 entre oficinas, inclusive status e duplicate), `Auth/*`, `Settings/*`.
- Adicionados: `EstimateIntegrityTest` (edit/update de outra oficina → 404; ids não numéricos → 404), `CreateBusinessCommandTest` (caixa do e-mail), `ProfileUpdateTest` (e-mail normalizado).

## Limitações

Nada foi testado contra produção. Não li o `.env`. Não foi possível verificar o comportamento do proxy da Railway (S04) nem o mailer (S06).
